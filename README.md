# AlgoEng

The code is written in [rust](https://www.rust-lang.org/).

## Prerequisites

- rust
- make

## Usage

- You probably have unpacked the project by now from a .tar.bz2

- Copy the graph.fmi and the queries.txt into the top level. Then do

```bash
make
```

- This should call the main function of the program and run all problems.
Problem 2 output will be shown in the terminal, just like Problem 1 and 4.
Problem 5 output will be written in the results.txt on the top level of the directory.
